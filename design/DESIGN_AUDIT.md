## Откуда появился код врача

Ручной код подключения был техническим решением при реализации прежнего MVP. Пользователь не запрашивал его. В макете есть обычная регистрация, а фрейм `31:8613` содержит отдельное создание приглашения и подтверждение пациентом; обязательного поля «код от врача» в регистрации нет.

Исправлено: на входе есть обычная регистрация. Врач передаёт ссылку-приглашение, которую пациент открывает и принимает. Секретный одноразовый токен остаётся внутри ссылки для защиты доступа, но вручную его вводить не нужно. Старый API активации сохранён для совместимости. Демо-кнопки доступны только при явном `?demo=1`.

Можно сначала зарегистрироваться, затем принять приглашение врача с паролем существующего аккаунта. До принятия нет доступа к карточке и уведомлениям наблюдения; пароль не меняется. Совпадение телефона/почты не открывает чужую историю и не переводит пациента от другого врача.
