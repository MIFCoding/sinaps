## Иконка приложения

Платформенные ресурсы в `apps/mobile/src-tauri/icons` созданы штатной командой:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/generate-icons.ps1
```

Сначала должен быть инициализирован Android-проект (`scripts/android.ps1 -Mode Init`). Манифест `apps/mobile/icon.json` использует исходный SVG СИНАПС. Скрипт создаёт передний слой с полями: знак занимает 64 из 108 единиц, поэтому круглая маска не обрезает логотип. Подготовлен также монохромный ресурс для тематических иконок.

Текущий источник — предоставленный пользователем `sinaps-logo-no-text.svg` (25.10.2026), сохранённый без изменения геометрии в `apps/frontend/public/design/synapse-logo.svg`. Обновлены общий компонент Brand, favicon, PNG/ICO/ICNS, Android и ресурсы iOS. Для интерфейса и favicon изменена версия URL, чтобы браузер перечитал файл. Веб-вход, кабинет и мобильная шапка проверены; в установленном Android проверены вход, кабинет и ярлык домашнего экрана без надписи внутри знака.

Tauri записывает Android-ресурсы прямо в `gen`; скрипт сохраняет их в `icons/android`. `build.rs` переносит эту копию обратно при сборке. Это предотвращает возврат старой иконки с пульсом после пересборки и повторного `android init`. Конфигурация Tauri явно ссылается на PNG/ICO/ICNS. По запросу пользователя Android-иконка не имеет белой окантовки: фон `apps/mobile/icon-background.svg` полностью заполнен фирменным `#239F8D`, белый рисунок расположен внутри знака. Отдельный монохромный слой сохраняет силуэт исходного SVG. Прозрачная подложка в проверенном лаунчере давала чёрный круг, поэтому итоговый фон непрозрачный. Логотип внутри интерфейса остаётся исходным SVG пользователя.

В собранном APK проверены ссылка launcher на `ic_launcher.xml` и побайтовое совпадение foreground-изображения xxxhdpi с ресурсом, полученным из исходного SVG.
